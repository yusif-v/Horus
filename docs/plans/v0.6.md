# Horus v0.6 — Web UI Foundation

*Date: 2026-06-08 (estimated)*

## Goal
Add web dashboard for browsing CVEs and PoCs.

## What Was Built
- Flask web server with Jinja templates
- Dashboard with threat posture grid (actionable, weaponized, imminent, PoCs linked)
- CVE list with severity/KEV/sort filters
- CVE detail page with affected products, attack tags, linked PoCs
- PoC list with source filter
- Triage queue (KEV + EPSS≥0.5 + weaponized)
- Search functionality
- REST API: `/api/stats`, `/api/cve/<id>`

## Design
- Dark theme with operational amber accent
- Responsive layout
- No authentication (localhost only)
