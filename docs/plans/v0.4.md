# Horus v0.4 — Domain Model & SQLite

*Date: 2026-05-21*

## Goal
Introduce typed domain model, closed vocabularies, and SQLite storage.

## Changes

### Domain Model
- `CVE`, `PoC`, `AffectedProduct` dataclasses in `horus/model.py`
- Closed vocabularies: 21 attack tags, 18 product categories
- CWE→tag and product→category lookup tables
- Classifier: CWE-priority + keyword-fallback attack tagging

### SQLite Storage
- `horus/storage/db.py` — schema init, vocab seeding, JSON migration, CRUD
- `horus/storage/schema.sql` — DDL, idempotent
- One-shot migration: imports `seen_items.json` + `last_run.json`, renames to `.migrated`
- Strict PoC↔CVE linking: edges only when CVE exists in table

### Merge Layer
- `horus/merge.py` — folds raw NVD + GitHub results into typed objects
- NVD source extracts CWE IDs and CPE-derived affected vendor/product/versions
- Reports group CVEs by product category, show attack tags + affected products

### Package Restructure
- `horus/core` — pure domain (model, vocab, classify, filters, merge)
- `horus/sources` — network ingestion (http, auth, github, nvd)
- `horus/storage` — local persistence
- `horus/render` — output formatting
