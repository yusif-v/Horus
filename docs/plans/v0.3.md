# Horus v0.3 — CLI Polish

*Date: 2026-05-20*

## Goal
Add CLI flags, Markdown output, and GitHub authentication.

## Changes
- Added flags: `--min-cvss`, `--max-results`, `--format {text,md}`, `--quiet`, `--version`
- Markdown output mode for chat-friendly delivery (Telegram, Slack)
- Per-source last-run tracking in `state/last_run.json`
- Adaptive NVD lookback: window stretches to previous run (capped at 14 days)
- Progress lines go to stderr (was stdout)
- GitHub auth: token from `GITHUB_TOKEN`, `GH_TOKEN`, or `gh auth token`
- `--auth-status` flag to verify token detection
