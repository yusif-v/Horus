# Horus v0.5 — Interactive Graph Viewer

*Date: 2026-05-21*

## Goal
Add interactive graph visualization of CVE/PoC/product relationships.

## Changes
- `horus/render/graph.py` — single self-contained HTML file per run
- Cytoscape.js (CDN) for force-directed layout
- Node types: CVE (size by CVSS), PoC (size by stars), Product, AttackTag
- Edge types: `tagged` (CVE→tag), `affects` (CVE→product), `references` (PoC→CVE)
- Click node to highlight neighborhood + view details in side panel
- Floating/orphan nodes filtered out
- `--no-graph` flag to skip generation
- XSS-safe: all untrusted strings via `textContent` / DOM construction
