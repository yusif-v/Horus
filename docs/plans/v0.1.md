# Horus v0.1 — Initial Prototype

*Date: 2026-05-19*

## Goal
Build a minimal CVE + PoC scanner that runs daily and delivers results to Telegram.

## What Was Built
- GitHub PoC repo scanner (keyword search, <30d old, >10 stars)
- NVD CVE feed integration (CVSS scores, severity levels)
- Deduplication via `state/seen_items.json`
- Telegram delivery via Hermes cron job
- X/Twitter search via xurl (pay-per-use)

## Data Sources
- GitHub API (free, no auth)
- NVD API (free, no auth)
- X/Twitter via xurl (pay-per-use)

## Known Limitations
- X/Twitter search requires paid X API
- Nitter mirrors unreliable for web scraping
- GitHub search limited to public repositories
- No database — JSON state files only
- No web UI — CLI + Telegram only

## Architecture
Single monolithic `horus.py` file. No package structure.
