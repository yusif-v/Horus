# Horus v0.2 — Package Restructure

*Date: 2026-05-20*

## Goal
Split monolithic `horus.py` into a proper Python package.

## Changes
- Split into `horus/` package: `config`, `state`, `filters`, `http`, `report`, `cli`, `sources/{github,nvd}`
- Entry point: `python3 -m horus` (replaces `python3 horus.py`)
- Removed X/Twitter (`xurl`) integration — no longer used

## Architecture
```
horus/
├── cli.py          argparse + dispatch
├── config/         paths, queries, tunables
├── filters/        CVE extraction, PoC relevance
├── http/           fetch_json + urlopen wrapper
├── report/         text output formatting
├── state/          JSON persistence (seen_items, last_run)
└── sources/        github.py, nvd.py
```
