# v0.9.x — Follow-ups after Tier 4

The big code-quality landing in v0.9 wired up `pyproject.toml`, ruff,
mypy, pre-commit, pytest-cov, and killed the `datetime.utcnow()`
deprecation warnings. Three follow-ups didn't fit in that PR and are
tracked here so they don't get lost.

## v0.9.1 — Coverage lift to 70 %

Current: **27.6 %** (gate at 25 %). The original v0.9 plan called for
70 %; getting there is a multi-step effort, not a single PR.

- [ ] **`tests/web/`** — most of the gap. Today only `test_routes.py`
      exists. Add:
      - `test_window_filter.py` — `/cves?window=…` returns expected row
        counts against a seeded DB.
      - `test_kev_toggle.py` — chip toggles on/off, preserves other
        params.
      - `test_pocs_routes.py`, `test_search_routes.py`,
        `test_triage_routes.py` — each route's happy path + a 4xx
        path.
      - `test_api.py` — `/api/stats` and `/api/cve/<id>` JSON contracts.
- [ ] **`tests/storage/`** — covers `db.py` ~60 %; needs
      `test_health.py` (each `_check_*` function), and round-trip tests
      for `persist_cves` + `persist_pocs` against an in-memory DB.
- [ ] **`tests/sources/`** — mock `fetch_json` and assert each source's
      `run(ctx)` output shape against canned NVD / GitHub / GitLab /
      Exploit-DB fixtures. Catches contract drift early.
- [ ] **`tests/enrichers/`** — EPSS CSV parsing + KEV JSON parsing
      against fixture files (no network).
- [ ] **Bump `--cov-fail-under`** from 25 → 70 in `pyproject.toml` once
      we're past it. Optional ratchet: bump by 5 % each PR so the gate
      never lies.

## v0.9.2 — Expand mypy --strict

Current scope: `horus/core/*`, `horus/pipeline.py` (8 files, 0 errors).
Expand layer by layer in the order from `code-quality.md` Tier 3:

- [ ] **`horus/storage/`** — well-bounded contract (sqlite3 rows in,
      dataclasses out). Will need `row_factory = sqlite3.Row` typed,
      and probably a `TypedDict` per persisted row shape.
- [ ] **`horus/sources/` + `horus/enrichers/`** — talk to JSON APIs.
      Define `TypedDict` for NVD response shape, GitHub repo shape,
      etc. Replace the loose `dict[str, Any]` returned from `run(ctx)`
      with a typed `SourceResult` so downstream code in `pipeline.py`
      knows what it's holding.
- [ ] **`horus/net/`** — `http.py`, `auth.py`, `xsearch.py`. xsearch
      is the messy one (Chrome cookie decryption); a `# type: ignore`
      island is fine if the cleanup isn't worth it.
- [ ] **`horus/web/`** — last. Flask + Jinja typing is its own fight;
      flask-stubs are mature now, so worth doing once everything else
      is green.

Each expansion is its own PR. Add the module under a new
`[[tool.mypy.overrides]]` block in `pyproject.toml` so the previous
layer can't regress.

## v0.9.3 — Supply chain (Tier 5 from `code-quality.md`)

- [ ] **`pip-audit`** in CI. Gate on `cve_severity >= HIGH` so it
      doesn't fail the build on every new advisory. Run on PR + nightly
      cron against `main`.
- [ ] **Dependabot** for `pyproject.toml` + GHA workflows. Group dev
      dependencies (ruff/mypy/pytest) into one weekly PR; keep runtime
      deps (Flask/PyYAML/gunicorn) separate.
- [ ] **`SBOM` (CycloneDX)** generated on release. `cyclonedx-py
      requirements pyproject.toml -o sbom.json` in the release
      workflow, attached to the GitHub release as an asset.
- [ ] **Sigstore signing** of release artifacts (wheel + sdist + SBOM)
      via `actions/attest-build-provenance`. Nice-to-have.
